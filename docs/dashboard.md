# Dashboard (Streamlit)

## Páginas
- Visão Produto: dataset/modelo ativos, métricas, drivers
- Clusters: UMAP, distribuição de conversão, palavras-chave
- Vendedores: recomendações personalizadas e evolução
- Drill-down: trechos de transcrição anonimizados por padrão

## Boas práticas
- Não exibir PII
- Filtros por produto, período, vendedor
