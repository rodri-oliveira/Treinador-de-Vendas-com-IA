# Convenções de Commits e Branching

## Conventional Commits
- feat, fix, docs, chore, refactor, test, perf, build, ci
- Ex.: `docs: add architecture overview`, `feat(audio): enable VAD`

## Branching
- main (estável)
- develop (integração)
- feature/<slug>

## Versionamento
- SemVer `0.x` no MVP
- Registrar mudanças em `docs/changelog.md`
