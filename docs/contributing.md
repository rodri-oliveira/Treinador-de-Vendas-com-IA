# Contribuindo

## Requisitos
- Python 3.10+
- Execução local (CPU)

## Padrões
- Pequenos PRs, escopo claro
- Atualizar `docs/` quando a mudança afetar arquitetura/uso
- Testes básicos para funções críticas (limpeza, anonimização, métricas)

## Fluxo
- Branch `feature/<slug>` → PR para `develop` → revisão → merge
