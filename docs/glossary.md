# Glossário

- Conversão: evento de sucesso da venda conforme KPI do produto
- Prosódia: características da voz (pitch, energia, ritmo)
- CTA: Call To Action (chamada à ação)
- Dataset Version: versão dos dados usados para treino
- Model Version: versão dos artefatos de modelo
- PII: Informações Pessoais Identificáveis
